# loon-rules

Loon 分流规则订阅仓库。

## 菲律宾规则（走 PureVPN 菲律宾节点）

订阅链接（Loon 远程规则，直接复制导入）：

```
https://raw.githubusercontent.com/Evaaaaa1/loon-rules/main/loon-ph-rules.list
```

导入方法：Loon → 配置 → 规则 → 远程规则 → 添加，粘贴上面的链接。

前提：菲律宾 WireGuard 节点在 Loon 里命名为 **PureVPN-PH**（规则按这个策略名引用；节点不叫这个名字时改节点名，或改规则文件里的策略名）。

覆盖范围：Maya（maya.ph / mayabank.ph / paymaya.ph / paymaya.com）、Coins.ph、ChatGPT 与 OpenAI、MEXC、ether.fi。文件内另有 DITO 与 GEOIP 菲律宾兜底两条可选规则，默认注释。
